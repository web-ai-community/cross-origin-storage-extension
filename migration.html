Cross-Origin Storage

Move files to your browser's storage

Checking what there is to move…

Your browser now supports Cross-Origin Storage itself, so sites no longer need this extension to share files. The extension stored for you (), which can move into the browser's own storage, so sites can keep using them without downloading them again.

  • Each file moves fully the next time you visit a site that stored it: the extension copies it into the browser's storage from that site, so the same sites keep access to it, and then deletes its own copy.

You can come back to this page any time from the extension's options.
