# Browser bug repros

Minimal reproductions of the engine bugs the extension works around. Each folder
holds a draft bug report (`README.md`) and the files to attach to it.

## Serving

```sh
node browser-bugs/serve.mjs   # http://localhost:8123/
```

The server also streams generated bytes at `/bytes/<n>`, which some pages use as
a network source.

## Safari

| Repro                                                                      | Kind      | Status in Safari Technology Preview 27.0 (21627.1.4.19.1)              |
| -------------------------------------------------------------------------- | --------- | ---------------------------------------------------------------------- |
| [cache-storage-2gib](safari/cache-storage-2gib/)                           | page      | Web process crash at exactly 2^31 bytes                                |
| [blob-constructor-crash](safari/blob-constructor-crash/)                   | page      | Web process crash above ~1.4 GiB from parts, above 2 GiB from one part |
| [blob-read-100mib](safari/blob-read-100mib/)                               | page      | Every whole-Blob read fails above 104,857,600 bytes                    |
| [sendmessage-binary](safari/sendmessage-binary/)                           | extension | Not yet run in Safari                                                  |
| [content-script-double-injection](safari/content-script-double-injection/) | extension | Not yet run in Safari                                                  |

To load an extension repro in Safari, enable Develop > Developer Settings >
Allow unsigned extensions, then choose Develop > Add Temporary Extension and
pick the extension folder. Allow it on `localhost` when Safari asks.

## Firefox

| Repro                                       | Kind | Status                 |
| ------------------------------------------- | ---- | ---------------------- |
| [sha256-js-speed](firefox/sha256-js-speed/) | page | Not yet run in Firefox |

The same benchmark measured about 240 MiB/s in Safari Technology Preview 27.0
and 250 to 270 MiB/s in Chrome 159, so the extension's note about Safari being
slow at this loop no longer reproduces.
