Throughput of a SHA-256 written in JavaScript

Hashes the same in-memory bytes, 4 MiB at a time, with createSha256() (Int32Array state, a 64-entry message schedule, and >>>/| rotations), and with crypto.subtle.digest() on one buffer as a baseline. No I/O is involved. Both hashes must agree.

Query parameters: sizes= MiB, comma-separated (default 64,256,512); autorun.
