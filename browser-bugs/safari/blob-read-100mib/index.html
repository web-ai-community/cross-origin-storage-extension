Reading a Blob of more than 100 MiB whole

Builds Blobs of several sizes from several sources and reads each one whole with several APIs. Slicing the same Blob into 4 MiB pieces and reading those is the control.

Query parameters: sizes= MiB, comma-separated; sources= any of memory,network,cache,response; autorun. The network source needs serve.mjs, which serves /bytes/<n>.
