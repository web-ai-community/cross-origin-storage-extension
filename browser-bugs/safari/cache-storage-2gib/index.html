Cache Storage: cache.put() of a 2 GiB entry

Stores one generated entry of each size with cache.put(), reads its size back, and deletes it. Each run writes up to ~2 GiB to disk, one entry at a time.

Query parameters: mode=stream (default, a ReadableStream body), mode=blob (a Blob built from 64 MiB parts), or mode=network (the Response of a fetch() of /bytes/<size> from serve.mjs); sizes= a comma-separated list of byte counts; autorun. Safari reloads a tab whose web process crashed, which reruns autorun, so leave it off for sizes that crash.
